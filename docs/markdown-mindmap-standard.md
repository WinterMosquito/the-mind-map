# Markdown ↔ 思维导图映射标准（The Mind Map）

> 关联实现：`src/md-outline.ts` / `src/md-serialize.ts` / `src/view-wikilink.ts`
> 回归测试：`scratch/md-roundtrip/`（56 断言：解析结构、层级深度、往返不动点、编辑合成；含代码围栏 opaque 与深树防溢出回归）
>
> 本标准定义：一个标准的 Obsidian Markdown 文件如何映射为思维导图、以及导图中的编辑如何无损写回该 Markdown。**所有渲染/回写行为以此为准**；实现与本标准不一致处视为缺陷。

---

## 1. 定位与触发

- 插件是 Markdown 的**渲染层**：`.mindmap.md` 是 100% 标准 Markdown，无任何专有格式/标记。
- **触发**：文件名以 `.mindmap.md` 结尾（大小写不敏感）→ 通过命令面板「以思维导图打开」或文件右键同名项，把当前标签页切换到导图视图（编辑模式与阅读模式入口均可用）；「以 Markdown 编辑」随时返回，并恢复进入前的编辑/阅读模式。
- **打开方式记忆**：最后一次主动选择（「以思维导图打开」/「以 Markdown 打开（默认）」）记入插件状态；偏好为导图的文件在下一次以 markdown 视图打开时自动切入导图视图（双击/链接/恢复均生效）。
- 其余 `.md` 文件不受影响；```mindmap 代码块沿用同一解析（Markdown 大纲）。**专有格式（.mindmap JSON）支持已删除**，不再存在独立通道。

## 2. 结构映射（大纲 → 树）

**中心主题 = 虚拟文档根**（第 0 层，文本 = 去掉 `.mindmap` 后缀的文件名；仅当文件无任何标题时才作为内容树根）。虚拟根不产生 md 行。

> **布局与视口持久化**：正文保持纯 Markdown，布局（layout）与视口（缩放/平移）不写入文件；插件将其存于 `data.json`（`viewState`，按文件路径 key），随文件改名/删除迁移或清理。打开时恢复布局与视口，无保存记录时回退设置默认布局并 fit 全图。

| Markdown 构造 | 映射 |
|---|---|
| `#` ~ `######` 标题 | 第 1 ~ 6 级子主题，与 `#` 数量严格对应 |
| 标题下的无序/有序列表（缩进嵌套） | 该标题的子主题树；无缩进列表项 = 标题的下一级（层级延续） |
| 6 级标题下的列表缩进（Tab/空格） | **第 7 级及以上**（列表缩进降级法：`###### A` 下缩进 1 层的 `- x` = 第 7 级，2 层 = 第 8 级…） |
| 无标题的纯列表文档 | 列表项从第 1 级子主题起 |
| YAML frontmatter | 不参与导图；原样保留在文件头（编辑只重写正文） |
| 段落/引用 `>`/表格 | 合并为「多行文本节点」（plain）：内容保留、段落间空行归一（见 §6 降级） |
| 代码围栏（三个反引号/三个波浪号起止） | 围栏整体 opaque 并入 plain 文本节点：起止标记与内容（内部空行、缩进、类标题/列表行）逐行原样保留；围栏相邻的空行分隔保留，往返可再次识别 |
| 空行、`---` 分隔线 | 忽略（结构分隔信号） |

**层级规则**：
1. 标题按 `#` 数量形成标题栈；相邻标题级别相同/更浅时回到对应祖先（常规大纲语义）。
2. **跳级**（`#` 后直接 `####`）：按祖先链深度建层（不插入空层）；原始 `#` 数量记录在节点 `mdLevel`，回写不丢。
3. **多根**（文档含多个同级 `#`）：均挂虚拟根下（拍平为单树）；无空分支。
4. 标题之间无列表时即纯标题树；段落/列表混排时按出现顺序。
5. 解析与序列化均以迭代/显式栈实现，深层缩进（数万级）不会栈溢出；代码围栏内容 opaque 保留（回归见 `scratch/md-roundtrip/`）。

## 3. 行内映射

| Markdown 行内 | 节点表现 |
|---|---|
| `[[目标]]` / `[[目标\|别名]]` | 文本 = 别名‖目标名（剥壳，**无 `[[]]` 字面**）；首个链接进入节点链接（可点） |
| `[文本](url)` | 文本 = 链接文本；节点链接 = url（引擎可跳 http/库内路径） |
| `![[文件]]` / `![alt](url)` | 首个图片 → 节点图片（按比例统一尺寸）；文本回退为文件名/alt |
| 行内多个链接/图片 | 首个链接 → 节点链接、首个图片 → 节点图；**其余剥壳为显示文本**，原文由 mdRaw 保真 |
| `**粗体**` `*斜体*` `` `代码` `` `~~删除~~` 等轻标记 | **不剥离、原样保留**在文本（无损；富文本渲染未启用，见 §7 边界） |

## 4. 交互标准（wikilink）

| 操作 | 行为 |
|---|---|
| 悬停含 `[[..]]` 链接的节点 | Obsidian 原生页面预览（hover-link；需页面预览插件开启） |
| `Ctrl/Cmd + 点击` 节点 | 新标签页打开目标 |
| 点击节点链接图标（引擎 hyperlink 图标） | 在当前标签打开目标（悬停图标显示目标名 title） |
| 普通单击节点 | 选中/编辑（与导图编辑语义一致，不劫持） |

## 5. 回写与保真

- 行级**未编辑检测**：节点同时满足「`text` = 解析时派生文本（`mdDerivedText`）」且「图片未更换」→ 保存时**整行逐字回写原文**（`mdRaw`），文件中 `[[]]`/`[]()` 包裹、全部 token、格式原样保留。
- **段落内的链接属原文**：plain 多行文本节点不承载引擎链接/图片字段，因此未编辑段落中的 `[[]]`/`[]()`/`![]()` 一律随 `mdRaw` **逐字回写**（不会因「无 hyperlink」被判为清除链接而剥壳）；用户真正编辑该段文字后才走合成。
- **编辑过文本** → 合成回写：新文本 + 行尾单链接 token（首个链接）；句中其余链接归一为行尾单链（见 §6 降级）。
- **换图**（导图内设置新图）→ 只写新图 token（`![[库内路径]]`），不带旧显示名。
- 有序列表按最终顺序重新编号 1..n；列表标记（`-`/`*`/`+`）保留；多行续行保留并补 2 空格缩进。
- 树的新增节点（无 md 元数据）→ 按无序列表 `-` 输出（可再解析）。

## 6. 已知降级（不静默丢失，但格式/粒度归一）

| 场景 | 行为 |
|---|---|
| 段落/引用/表格 | 并入多行文本节点，内容保留；**段落间空行**在往返中归一 |
| 编辑含链接的句子 | 非首个链接 token 归一为行尾单链 |
| 编辑过文本的节点中的轻标记 | 标记文字随文本保存（用户可见），不再自动补 `**` 等 |
| 导图内对节点做**备注/样式/附件**（md 模式） | 已阻止并提示（无 md 回写语法） |

## 7. 边界与后续（方案 B 候选）

- 引擎节点文本为 SVG 文本（非 HTML）：无法实现"文中内联蓝色链接"字面效果；整链节点以「内部名文本 + 链接图标」呈现。方案 B（`customCreateNodeContent` 自绘节点）可做到内联，另立里程碑。
- frontmatter 触发（`type: mindmap`）为后续设置项。

## 8. 示例

输入 `项目计划.mindmap.md`：

```markdown
---
tags: [规划]
---
# 项目计划
## 目标
- 里程碑一
- 里程碑二
###### 细则
- 第 7 级列表项
  - 第 8 级列表项
## 分工
参见 [[设计稿|设计]] 与 [仓库](https://github.com/example) 说明
```

导图（中心 = `项目计划`）：
```
项目计划（中心主题）
├── 目标 ────── 里程碑一 / 里程碑二
├── 细则 ────── 第 7 级列表项 ── 第 8 级列表项   （######=6 级 + 列表缩进 → 7/8 级）
└── 分工 ────── "参见 设计 与 仓库 说明"（悬停预览 / Ctrl+点击跳转）
```

未编辑任何节点直接保存 → 文件逐字不变（frontmatter、`######`、`[[设计稿|设计]]`、`[仓库](…)` 全部原样）。
